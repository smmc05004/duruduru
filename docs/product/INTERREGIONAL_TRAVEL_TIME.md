# 지역 간 일반 예상 이동시간 설정

## 목적

DURUDURU가 필요한 값은 청사 간 거리나 실시간 길찾기가 아니라, 사용자가 출발 지역에서 여행 지역까지 자동차로 이동할 때의 **일반적인 지역 간 예상시간**이다.

MVP의 1차 원천은 한국교통연구원 국가교통DB(KTDB)의 지역 간 여객 O/D·교통분석 자료다. KTDB는 지역 간 교통수단별 통행시간·거리를 다루며, MVP는 그중 자동차 수단 값만 사용한다.

## 준비 절차

1. KTDB의 최신 지역 간 여객 O/D 또는 교통분석용 네트워크 자료를 공식 자료 신청 절차로 확보한다. 서비스 내 저장·조회·표시에 필요한 이용 허락이 무료로 가능한지 먼저 확인한다.
2. 사용할 연도·자동차 수단·통행시간 필드·지역 단위를 기록한다. 전체 수단 평균이나 대중교통 시간은 사용하지 않는다.
3. DURUDURU 지원 지역 ID와 KTDB 지역(교통존) ID를 연결한 매핑을 만든다.
4. 지역 간 시간 값을 `출발 지역 ID`, `도착 지역 ID`, `편도 예상시간`, `KTDB 자료 연도`, `원천 지역 ID`, `적재일`, `데이터 버전`으로 적재한다.
5. 같은 지역에 여러 KTDB 교통존이 대응하면 임의 평균을 내지 않는다. KTDB가 제공하는 지역 대표값을 사용하거나, 매핑·집계 규칙을 별도 결정한 뒤 적재한다.
6. 적재 결과에서 값이 없거나 0 이하인 쌍은 결측으로 남긴다. PoC 고정값·직선거리 환산·임의 평균으로 채우지 않는다.

## 앱에서의 사용

`갈 수 있는 곳 찾기`를 누르면 서버는 출발 지역 ID와 후보 여행 지역 ID로 적재된 편도 일반 예상시간을 조회한다. 왕복 시간은 같은 편도 값의 두 배다.

이 데이터는 검색 시 외부 API로 호출하지 않는다. 최신 관광지·음식점 데이터와 달리, 지역 간 일반 예상시간은 KTDB 기준연도·버전이 있는 기준 데이터로 관리한다.

결과에는 “자동차 일반 예상 이동시간”, KTDB 기준연도와 데이터 갱신일을 표시한다. 실시간 교통·사고·출발 시각·개별 주소 간 내비게이션 시간으로 표현하지 않는다.

## 결측과 갱신

- 출발 지역·여행 지역의 매핑 또는 시간 값이 없으면 해당 여행 지역을 추천하지 않는다.
- KTDB 새 자료를 확보하면 별도 적재 작업으로 전체 값을 갱신한다. 기존 데이터와 새 데이터의 기준연도·버전은 함께 보존한다.
- 앱 실행 중 자료를 덮어쓰지 않으며, 사용자별 경로 API 호출을 하지 않는다.
- KTDB 자료의 무료 이용·서비스 재사용 허락을 받을 수 없으면 이 원천을 사용하지 않고, 후속 OSRM 대안을 검토한다.

## 후속 대안: 자체 OSRM

KTDB 자료의 지역 단위가 DURUDURU 지원 단위와 맞지 않거나, 자동차 수단별 시간 값을 사용할 수 없는 경우에만 자체 OSRM 방식을 검토한다.

이 경우 공식 청사·행정 대표점 목록과 한국 OSM 도로망으로 자체 OSRM 그래프를 만들고, 대표점 간 일반 예상시간을 배치 계산해 저장한다. 공개 OSRM 데모 서버는 소량 검증용으로만 사용하며 서비스 운영이나 대량 수집에 사용하지 않는다.
