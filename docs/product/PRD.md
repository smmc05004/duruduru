# DURUDURU MVP 제품 요구사항

## 제품 정의

DURUDURU(두루두루)는 목적지를 먼저 정하지 않는 국내 여행 플래너다. 사용자가 출발지와 출발·복귀 가능 시간을 입력하면, 그 시간 안에 현실적으로 다녀올 수 있는 목적지를 먼저 추천하고 선택한 지역의 일정까지 생성한다.

기존의 “경주에 갈 건데 무엇을 하지?”가 아니라, “이번 주말 이 시간 안에 어디를 다녀올 수 있지?”를 해결한다.

## 문제와 대상 사용자

짧은 주말이나 연휴에 여행할 시간은 있지만 목적지를 정하지 못해 계획을 시작하지 못하는 사람이 대상이다.

MVP의 우선 대상은 1박 2일 또는 당일치기 국내여행을 계획하며, 출발지와 출발·복귀 가능한 시간이 명확한 자차 여행자다. 역사·문화·자연처럼 여행 취향이 있는 사용자를 먼저 지원한다.

## 핵심 가치

- 가용시간 안에 가능한 목적지를 먼저 제안한다.
- 선택한 지역을 어떻게 둘러볼지 판단할 수 있는 **실행 가능한 참고용 여행 계획**을 만든다. 이는 예약·내비게이션·분 단위 실행을 보증하는 일정표가 아니다. 검색을 시작할 때 최신 관광·음식점·운영 정보를 서버 API로 조회하고, 출발지와 여행지 대표점 간 직선거리 기반 일반 예상시간으로 가용시간을 계산한다. 실시간 교통·도로 길찾기·내비게이션은 제공하지 않으며 방문 전 최신 운영 정보 확인은 여전히 필요하다.
- 추천 이유와 시간 계산의 근거를 보여 사용자가 결과를 납득할 수 있게 한다.

## MVP 사용자 여정

1. 사용자가 출발지, 출발·복귀 일시, 자차 여부, 관심사를 입력한다. 관심사는 1개 이상 선택한다.
2. 시스템이 왕복 이동과 최소 현지 체류 가능 시간을 기준으로 목적지 후보를 걸러낸다. 여행 유형(당일치기 / 1박 2일 / 그 이상)은 출발·복귀가 걸치는 KST 달력일 수로 판별하고, 최소 현지 체류시간은 `4시간 × 일수`다.
3. 가능한 목적지 3~5개와 추천 이유, 왕복 예상 이동시간, 현지 이용 가능 시간을 제시한다.
4. 사용자가 한 목적지를 선택한다.
5. 시스템이 관심사에 맞는 관광지와 점심·저녁 식사를 1일차와 2일차에 배치한 참고 계획으로 생성한다. 관광지·음식점의 체류시간은 각각 1시간이며, 장소 내부 이동시간은 계산하거나 표시하지 않는다. 초기 완성 시나리오는 자차 1박 2일, 1일차 08:00 출발·2일차 20:00 복귀다.
6. 사용자는 일반 이동·방문 시간의 근거와 한계, 최신 운영 정보 확인 안내를 확인한다.

| P0       | 왕복 가능 여부와 최소 현지 체류시간 판정 (복귀 버퍼 없음)                                                               |
| P0       | 관심사 기반 목적지·장소 점수화                                                                                          |
| P0       | 날짜별 관광·점심·저녁 시간표를 제시하는 참고용 여행 계획 생성                                                           |
| P0       | 추천·일정의 이유와 시간 근거 표시                                                                                       |
| P1       | 여행 기간과 겹치는 축제 반영                                                                                            |
| P1       | 동선 최적화 기반 음식점 선정, 복수 대체 후보, 미식 관심사 큐레이션 (대표음식 기반 음식점 배치는 2026-08-31 결정으로 P0) |

## MVP 비목표

- 로그인, 개인화, 여행 저장·공유
- 도로 경로 API, 실시간 교통, 정밀 내비게이션, 예약·결제
- 맛집 평점·랭킹 (2026-08-31 음식점을 일정에 포함하기로 결정했으나 이 비목표는 유지된다. 선정 기준은 "지역 대표음식을 파는가"이며 평점·리뷰 수·순위를 선정·정렬에 쓰지 않는다)
- GPS 방문 인증, 스탬프, 컬렉션, 친구, 랭킹, 미션
- 전국 모든 지역과 모든 여행 조건의 즉시 지원
- LLM 기반 핵심 추천·일정 생성

## 품질 원칙

- **참고 계획의 정직성:** 매력도보다 사용 가능한 시간을 우선하되, 결과를 확정 일정이나 영업 가능 보증으로 표현하지 않는다.
- **설명 가능성:** 추천·제외·일정 배치의 근거를 표시한다.
- **불확실성 명시:** 검색 시점에 조회한 외부 데이터와 출발지↔여행지 대표점 직선거리 기반 일반 예상시간은 추정치·조회 시각·출처를 표시하고, 실시간 교통 및 영업 가능 보장으로 표현하지 않는다. 장소 내부 이동은 계산·표시하지 않는다.
- **데이터 품질 우선:** 수집된 운영·휴무 정보가 있으면 출처·갱신일을 관리하되, 그 정보가 없는 MVP 결과도 결측과 확인 행동을 숨기지 않는다.
- **점진적 확장:** 검증된 일부 지역에서 유용성을 입증한 뒤 지역을 넓힌다.

## 성공 지표

- 입력 후 목적지 후보 선택률
- 목적지 선택 후 일정 생성 완료율
- 참고 계획 생성 완료율
- 결과가 추정·결측·확인 필요 정보를 명확히 표시한 비율
- 일정 재생성·장소 교체 비율
- 추천 결과에 대한 간단한 만족 응답
- fallback 데이터 사용 비율

가장 중요한 검증은 사용자가 목적지를 정하지 않은 상태에서도 추천 결과를 납득하고 일정을 끝까지 생성하는지다.
