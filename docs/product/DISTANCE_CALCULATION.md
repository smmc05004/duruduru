# 거리 계산 방법

## 목적과 범위

MVP는 출발지와 여행지 사이의 가용시간만 판정한다. 관광지 내부 장소↔장소, 장소↔음식점, 음식점↔다음 장소 이동은 계산·표시·일정 제약에 사용하지 않는다.

이동시간은 실시간 교통·내비게이션 시간이 아니다. 출발 지역과 여행 지역 사이의 자동차 **일반 예상 이동시간**이며, 국가교통DB(KTDB)의 지역 간 자동차 통행시간을 기준으로 한 여행 계획 참고용 추정치다.

## 지역 간 이동시간

1. 서버는 출발 지역과 여행 지역에 연결된 KTDB 지역(교통존) 간 자동차 일반 예상시간을 사용한다.
2. 청사·군청·구청은 지역을 대표하기 위해 사용했던 초기 기준점일 뿐, 현재 MVP 시간 데이터의 계산 기준이 아니다.
3. 앱 서버는 적재된 지역 간 일반 예상시간만 조회한다. 사용자 검색 중 경로·지오코더·내비게이션 API를 호출하지 않는다.
4. 지원 지역 매핑 또는 일반 예상시간이 준비되지 않은 쌍은 추천 대상에서 제외하고, 임의의 시간으로 대체하지 않는다.

왕복 시간은 같은 편도 일반 예상시간의 두 배로 계산한다. 실제 교통·사고, 출발 시각은 반영하지 않는다.

지역 ID 매핑·적재·갱신과 OSRM 후속 대안은 [지역 간 일반 예상 이동시간 설정](INTERREGIONAL_TRAVEL_TIME.md)을 따른다.

## 검색 실행과 표시

`갈 수 있는 곳 찾기`를 클릭할 때 서버가 적재된 지역 간 일반 예상시간을 조회한다. 결과는 그 검색 스냅샷에 보존하고 목적지 선택·일정 표시에서 재사용한다. 다음 검색도 같은 기준 데이터를 조회한다.

결과 화면에는 출발지→여행지 일반 예상시간과 조회 시각만 간결하게 표시한다. 실제 경로·실시간 교통으로 오해하게 하는 문구는 사용하지 않는다.

## 결측과 실패

필요한 지역 매핑 또는 일반 예상시간을 얻지 못하면 임의 시간으로 대체하지 않는다. 해당 목적지는 추천하지 않으며, 데이터 조회 장애와 정상 응답이지만 지원 값이 없는 경우를 구분해 재시도를 안내한다.
