# 거리 계산 방법

## 목적과 범위

MVP는 출발지와 여행지 사이의 가용시간만 판정한다. 관광지 내부 장소↔장소, 장소↔음식점, 음식점↔다음 장소 이동은 계산·표시·일정 제약에 사용하지 않는다.

이동시간은 실시간 교통·내비게이션 시간이 아니다. 출발지와 여행지의 시·군·구 **시청·군청·구청 대표점 사이의 일반 예상 이동시간**이며, OSRM의 자동차 경로 결과를 개발 시점에 사전 수집한 여행 계획 참고용 추정치다.

## 대표점과 이동시간

1. 출발지와 여행지의 대표점은 해당 시·군·구의 시청·군청·구청으로 통일한다.
2. 개발 수집 도구가 청사 대표점 쌍을 OSRM 자동차 프로필로 조회해 도로 거리와 일반 예상시간을 함께 기록한다.
3. 앱 서버는 수집한 청사 쌍의 일반 예상시간만 조회한다. 사용자 검색 중 OSRM·지오코더·내비게이션 API를 호출하지 않는다.
4. 지원하지 않는 행정구역 쌍 또는 일반 예상시간이 준비되지 않은 쌍은 추천 대상에서 제외하고, 임의의 시간으로 대체하지 않는다.

왕복 시간은 같은 편도 일반 예상시간의 두 배로 계산한다. 실제 교통·사고, 출발 시각은 반영하지 않는다.

## OSRM 사전 수집 적용

수집 대상은 지원 출발지 청사와 지원 여행지 청사의 방향성 있는 쌍뿐이다. 현재 지원 범위에서는 서울특별시청·대전광역시청·부산광역시청에서 경주시청·공주시청·강릉시청까지의 3×3 편도 경로다. 관광지·음식점 내부 경로는 수집하거나 사용하지 않는다.

개발 수집 도구는 각 쌍의 WGS84 경도·위도를 OSRM `driving` 경로에 전달하고, 거리·예상시간·수집일·OSRM/OSM 출처·재현 식별자를 함께 저장한다. 공개 OSRM 서버는 소량의 수동 수집에만 사용하며, 서비스 런타임·대량 호출에는 사용하지 않는다. 원시 응답과 서비스 키는 저장하지 않는다.

수집된 값이 없거나 결측이면 해당 지역은 추천하지 않는다. 직선거리 환산, PoC 고정값, 임의 평균으로 대체하지 않는다.

## 검색 실행과 표시

`갈 수 있는 곳 찾기`를 클릭할 때 서버가 수집된 청사 쌍의 일반 예상시간을 조회한다. 결과는 그 검색 스냅샷에 보존하고 목적지 선택·일정 표시에서 재사용한다. 다음 검색도 같은 기준 데이터를 조회한다.

결과 화면에는 출발지→여행지 일반 예상시간과 조회 시각만 간결하게 표시한다. 실제 경로·실시간 교통으로 오해하게 하는 문구는 사용하지 않는다.

## 결측과 실패

필요한 대표점 또는 사전 수집 일반 예상시간을 얻지 못하면 임의 시간으로 대체하지 않는다. 해당 목적지는 추천하지 않으며, 데이터 조회 장애와 정상 응답이지만 지원 값이 없는 경우를 구분해 재시도를 안내한다.
