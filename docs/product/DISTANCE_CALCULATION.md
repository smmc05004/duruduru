# 거리 계산 방법

## 목적과 범위

MVP는 출발지와 여행지 사이의 가용시간만 판정한다. 관광지 내부 장소↔장소, 장소↔음식점, 음식점↔다음 장소 이동은 계산·표시·일정 제약에 사용하지 않는다.

이동시간은 실시간 교통·내비게이션 시간이 아니다. 출발지와 여행지의 시·군·구 **시청·군청·구청 대표점 사이의 일반 예상 이동시간**이며, 여행 계획 참고용 추정치다.

## 대표점과 이동시간

1. 출발지와 여행지의 대표점은 해당 시·군·구의 시청·군청·구청으로 통일한다.
2. 서버는 대표 행정구역 쌍의 일반 예상 이동시간을 사용한다.
3. 이 값은 도로 경로·직선거리·실시간 교통을 사용자 경험이나 일정 계산의 기준으로 노출하지 않는다.
4. 지원하지 않는 행정구역 쌍 또는 일반 예상시간이 준비되지 않은 쌍은 추천 대상에서 제외하고, 임의의 시간으로 대체하지 않는다.

왕복 시간은 같은 편도 일반 예상시간의 두 배로 계산한다. 도로망 방향, 실제 교통·사고, 출발 시각은 반영하지 않는다.

## 검색 실행과 표시

`갈 수 있는 곳 찾기`를 클릭할 때 지원 행정구역의 대표점과 일반 예상시간을 조회한다. 결과는 그 검색 스냅샷에 보존하고 목적지 선택·일정 표시에서 재사용한다. 다음 검색은 새 데이터를 조회한다.

결과 화면에는 출발지→여행지 일반 예상시간과 조회 시각만 간결하게 표시한다. 실제 경로·실시간 교통으로 오해하게 하는 문구는 사용하지 않는다.

## 결측과 실패

필요한 대표점 또는 일반 예상시간을 얻지 못하면 임의 시간으로 대체하지 않는다. 해당 목적지는 추천하지 않으며, 데이터 조회 장애와 정상 응답이지만 지원 값이 없는 경우를 구분해 재시도를 안내한다.
