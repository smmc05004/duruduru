# 제품 결정 기록

> 이 문서는 현재 MVP에 유효한 제품 결정을 한곳에 기록한다. 과거 PoC 구현 방식이나 폐기된 정적 데이터 정책은 다시 가져오지 않는다.

## 확정

| 주제               | 결정                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 제품 경험          | 목적지를 정하지 않은 사용자가 출발지·가용시간을 입력하면, 가능한 여행 지역부터 추천하고 선택한 지역의 참고용 1박 2일 계획을 본다.                                                                                                                                                                                                                                     |
| MVP 기준 시나리오  | 자차, 1일차 08:00 출발, 2일차 20:00 복귀다. 입력은 출발지·출발/복귀 일시·자차·관심사다.                                                                                                                                                                                                                                                                               |
| 지역 간 이동시간   | 실시간 교통이나 내비게이션 시간이 아닌 자동차 일반 예상시간만 쓴다. KTDB 2024 도로 네트워크의 252존 중심 노드 간 승용차 기본 링크 비용으로 사전 산출하고, 검색 중 경로 API를 호출하지 않는다.                                                                                                                                                                         |
| 지역권 범위        | 경주·공주·강릉은 초기 예시·검증 지역이며 지원 목적지의 전부가 아니다. 출발지와 목적지는 KTDB 2024의 전국 252개 지역권을 쓴다. 출발지 입력은 252개 지역권에 대응하는 시·군·구명 선택 또는 검색으로 제공한다.                                                                                                                                                           |
| 지역 내부 이동     | 관광지↔관광지, 관광지↔음식점, 음식점↔다음 장소의 이동시간은 계산·표시·일정 제약에 사용하지 않는다.                                                                                                                                                                                                                                                                    |
| 시간표 규칙        | 관광지와 음식점은 각각 1시간이다. 21:00~~07:00은 휴식으로 고정한다. 점심은 11:30~~13:30, 저녁은 17:30~19:30에 각각 1시간을 반드시 배치한다.                                                                                                                                                                                                                           |
| 후보 검색 흐름     | `갈 수 있는 곳 찾기`에서 출발 지역권→전국 252존의 왕복 일반 예상시간으로 먼저 시간 적합 후보를 만든다. 그 후보에만 최신 관광지, 음식점 목록 기본 정보·대표음식 근거를 제한 동시성·페이지네이션으로 연결하고 최종 3곳을 고른다. 최종 후보 선택 뒤에는 새 외부 API를 호출하지 않고 검색 스냅샷으로 계획을 만든다.                                                       |
| 관광지·음식점 원천 | 관광지와 음식점 최신 정보는 서버의 TourAPI KorService2 호출로 가져온다. 대표음식 시드는 지역N문화, 공식 지정 여부는 모범음식점 데이터를 사용한다.                                                                                                                                                                                                                     |
| 음식점 선정·상세   | 검색 단계에서는 대표음식 근거 또는 기본 목록 정보가 있는 후보를 식사 블록에 배치한다. 메뉴·운영시간·휴무는 조회·판정하지 않는다. 사용자가 음식점을 클릭하면 서버 Route Handler가 TourAPI `detailIntro2`를 호출해 상세를 보여 준다. 상세 결과는 일정 시간표를 바꾸지 않는다. 복수 후보는 공식 지정 여부, 안정적인 장소 ID 순으로 고른다. 평점·리뷰·랭킹은 쓰지 않는다. |
| 제외 범위          | 유료 API, 실시간 교통, 도로 길찾기, 정밀 내비게이션, 예약·결제, LLM 핵심 추천, 스탬프·친구·랭킹·방문 인증은 MVP 범위 밖이다.                                                                                                                                                                                                                                          |
| 실패 처리          | 필요한 관광지·음식점 기본 정보·일반 예상시간이 없으면 임의 고정값이나 PoC fallback으로 대체하지 않고 해당 후보를 제외하거나 재시도를 안내한다. 음식점 상세 호출 실패는 해당 상세의 재시도로 구분한다.                                                                                                                                                                 |

## 현재 준비 상태

- KTDB 252존 기반 지역 간 일반 예상시간 테이블은 `data/ktdb/interregional-travel-times-2024.json`에 생성돼 있다.
- TourAPI 법정동 코드와 KTDB 252존의 전국 매핑은 목적지 검색 전제이며, 현재 코드의 고정 3개 출발지·목적지 목록은 이 문서 기준선과 불일치한다. 해당 목록과 정적 어댑터는 전국 매핑·검색 흐름으로 교체해야 한다.
- 울릉군·제주시·서귀포시는 도로망으로 연결되지 않아 결측이며, 항공·선박은 MVP 범위 밖이다.
- TourAPI 서비스 키는 개발 환경에 설정돼 있다.
- 지역N문화 대표음식 파일은 무료 원천이 확인됐지만, 플랫폼의 활용 목적·약관 동의 후 내려받아 정규화해야 한다.

## 보류

- 시간대별 혼잡, 실시간 교통, 상세 주소·장소 간 이동시간은 고도화 단계에서 검토한다.
- 복수 대체 음식점, 동선 최적화, 일정 재생성·장소 교체, 대중교통·날씨·예산은 P1 이후다.
