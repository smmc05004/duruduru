# DURUDURU 디자인 방향

## 확정 방향 — H · 여행 수첩

여행자가 직접 적어 내려간 수첩의 인상을 기본으로 한다. 크라프트 톤 종이 바탕, 진한 잉크 테두리와 하드 섀도로 실물감을 만들고, 지역 정보는 스티커 라벨처럼 붙인다. 제목은 둥근 고딕으로 또렷하게, 손글씨는 강조 한 곳에만 쓴다.

| 항목 | 내용 |
| --- | --- |
| 성격 | 친근하고 손으로 만든 느낌. 도구보다 동반자에 가깝다 |
| 제목 | 둥근 고딕(Jua) — 부드럽지만 획이 균일해 작은 크기에서도 읽힌다 |
| 본문·수치 | Gothic A1 500~700 — 정보 밀도가 올라가도 버틴다 |
| 손글씨 | Gaegu. 강조 라벨 한 곳에만. 제목·본문·수치에는 쓰지 않는다 |
| 바탕 | 크라프트 종이 톤 + 점 패턴 |
| 강조 | 올리브 그린(가능·통과), 머스터드(축제·기간), 테라코타(추천 라벨) |
| 시간 표현 | 둥근 막대로 이동/체류 비율을 한 줄에 |

토큰 값은 `docs/design/DESIGN_TOKENS.md`에 있다.

추천·참고 계획 결과에서 사용자용 판단 정보와 선택형 데이터 근거를 나누는 규칙은 `docs/design/RESULT_INFORMATION_HIERARCHY.md`에 있다.

### 왜 H인가

C(여행 수첩)의 분위기가 제품 성격에 가장 맞았다. 목적지를 정하지 못한 사람에게 필요한 것은 정밀한 계기판보다 "같이 골라주는" 인상이다.

다만 C는 손글씨체가 제목·본문·수치를 전부 맡아 작은 글씨가 읽히지 않았다. H는 **분위기를 만드는 요소(종이·색·스티커·하드 섀도)는 그대로 두고 서체 역할만 나눈 것**이다. 손글씨를 액센트로 물리고 제목을 둥근 고딕으로 옮기자 가독성 문제가 사라졌다.

### 탈락한 방향과 이유

같은 화면(추천 결과)을 여덟 방향으로 그려 비교했다. 작업 파일은 `design/`에 있다.

| 안 | 축 | 탈락 이유 |
| --- | --- | --- |
| A · 여행 잡지 | 명조 세리프, 넉넉한 여백, 읽는 맛 | 여행지는 매력적으로 보이나 시간 정보가 약하다 |
| B · 시간 계기판 | 다크, 모노 숫자, 비율 막대 | 차별점은 잘 보이나 여행의 설렘이 없다 |
| C · 여행 수첩 | 손글씨, 종이 질감, 스티커 | **분위기는 채택.** 손글씨가 전부를 맡아 가독성이 무너짐 |
| D · 대담한 편집 | 초대형 헤드라인, 흑백 + 주황 | 첫인상은 강하나 정보량이 늘면 유지가 어렵다 |
| E · 수첩 + 굵은 제목 | C 유지 + Black Han Sans 제목 | 제목체가 각지고 무거워 D 쪽 포스터 성격으로 밀렸다 |
| F · 스티커 팝 | D 뼈대 + 수첩 액센트 | 같은 이유로 C의 분위기에서 더 멀어졌다 |
| G · C + 또렷한 본문 | 손글씨 제목 유지, 본문만 교체 | H와 근접. 개성은 세지만 지명이 길어질 때 제목이 약하다 |
| H · C + 둥근 제목체 | 손글씨는 액센트로, 제목은 둥근 고딕 | **채택** |

E·F에서 배운 것을 남긴다. **제목 서체 하나가 방향 전체를 끌고 간다.** 나머지 요소를 모두 유지해도 제목체를 바꾸면 다른 방향이 된다.

### 아직 정하지 않은 것

- 다크 모드 지원 여부와 그때의 종이 표현
- 데스크톱 폭에서의 레이아웃(현재 방향 탐색은 모바일 390px 기준)
- 사진 사용 여부. 현재 시안은 색과 도형만 쓴다
