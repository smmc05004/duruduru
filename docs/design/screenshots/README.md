# 구현 화면 스크린샷

이 디렉터리는 **실제로 구현된 화면을 브라우저에서 찍은 결과**다. 설계 시안이 아니다.

- 설계 시안(무엇을 만들 것인가)은 `design/screens/`의 `.dc.html` 파일이다.
- 이 디렉터리(무엇이 실제로 나왔는가)는 그 시안대로 구현했는지 눈으로 확인한 기록이다.

둘이 어긋날 수 있다. 어긋난 곳은 구현 커밋의 완료 보고와 PR에 남긴다. **기준은 시안과
`docs/product/FUNCTIONAL_SPEC.md`이고, 이 스크린샷은 근거이지 기준이 아니다.**

## 갱신 시점

**구현이 바뀌면 이 스크린샷은 낡는다.** 아래 표의 커밋 이후 해당 화면을 바꾸는 변경을 하면
같은 조건으로 다시 찍어 교체한다. 교체하지 않을 거면 표에서 지운다 — 낡은 이미지를 남겨 두면
다음 사람이 현재 화면으로 오해한다.

## 목록

찍은 날짜: **2026-09-01** · 대상 커밋: **`3fce26d`** (F-02·F-03 추천 결과 화면)
환경: `npm run dev`, Chromium, 뷰포트 폭 420px, 전체 페이지 캡처
