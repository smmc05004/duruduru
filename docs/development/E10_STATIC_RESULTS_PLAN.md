# E10 정적 경로 데이터와 기본 결과 활성화 계획

## 목표

지원하는 서울특별시·대전광역시·부산광역시 출발, 경주·공주·강릉 목적지 조합에서 런타임 외부 호출 없이 실제 사전 수집 경로와 실제 TourAPI 장소 앵커를 사용해 추천과 참고용 여행 계획을 표시한다.

## 범위

1. 3×3 도시 기준점의 자동차 편도 도로 경로 거리·일반 예상시간을 정적 매니페스트에 기록한다.
2. 각 목적지에서 표시하는 두 TourAPI 장소의 관심사 근거와 방문시간 추정 근거를 연결하고, 표시 순서에 필요한 방향성 경로를 기록한다.
3. 추천 어댑터와 참고 계획 어댑터가 같은 정적 매니페스트를 읽게 한다.
4. 기본 추천 → 후보 선택 → 참고 계획의 Jest·Playwright 흐름을 검증한다.

## 데이터와 경계

- 좌표는 승인된 지원 조건의 시청 기준점 및 2026-09-03 수집 TourAPI 장소 원천 좌표를 쓴다.
- 경로는 2026-09-03 OSRM 공개 데모 서버의 소량 수동 조회 결과와 OSM 도로 데이터를 기록한다. 공개 서버를 배치·런타임·대량 수집에 사용하지 않는다.
- 값은 `estimate`이며 실시간 교통 또는 내비게이션 보증이 아니다. 값·좌표·수집일·버전·재현 식별자·이용 조건 확인을 함께 남긴다.
- 운영·휴무·음식점 정보는 이번 수집에 없으므로 결측을 유지한다. 사용자 자유 입력 주소, 런타임 지오코딩·경로 API는 추가하지 않는다.

## 위험과 검증

- 수동 경로값이 출처 없이 보이지 않도록 매니페스트 검증을 통과해야 한다.
- 지원하지 않는 쌍과 명시적 결측은 계속 `null`로 조회되는 테스트를 유지한다.
- `npm run verify`, `npm run test:e2e`와 독립 reviewer 검토를 완료한다.
