# 추천 품질 R5 구현·검증 결과

> 2026-09-14. R3 승인 정책을 R4에 구현한 결과다. 코드 검증과 사용자의 추천 품질 수용은 별개이며, 전국 명소의 중요도를 정확히 순위화했다는 주장은 하지 않는다.

## 구현 범위

- 새 검색은 가까운 여행 → 1박 2일 여행 → 관심사 중심 여행 순서로 최대 3개 서로 다른 지역을 선택한다.
- 역할별 시간 구간·실제 시설 그룹·관심사 조건·동점 정렬은 [제품 정책](../product/RECOMMENDATION_QUALITY_RECOVERY.md#r3-확정-정책-2026-09-14)을 따른다.
- 검색 버전은 `e1-v4`, 일정 버전은 `e2-v3`이다. 구 저장본의 역할과 버전은 재해석하지 않는다.
- 데이터 재수집·검색 외부 API 호출·도시 가점·전국 hubRank 비교를 추가하지 않았다.

## 해석과 한계

- 서울·역사·주간은 고양·문경·순창을 제공한다. 기존 실제 세 장은 고양·과천·의왕이었다. 각 장소명·시설/유형·공주/익산/경주의 제외 이유는 [비교 보고서 §16](RECOMMENDATION_QUALITY_COMPARISON.md#16-r3-확정--새-역할이동시간-구간-정책)에 있다.
- 시간 목표(편도 120/180분)는 서로 다른 이동 부담을 제시하기 위한 승인된 제품 선호다. 도시의 문화적 가치 점수나 공식 권장 여행시간이 아니다.
- 시설·세부 유형이 풍부하다는 것은 현재 공공데이터와 실제 초안 기준이다. 상위 유적 단지 식별 한계, 음식점/운영 정보 원천의 결측, 전국 대표성 미검증은 그대로 남는다.
- 실제 화면 결과를 사용자가 수용하기 전에는 추천 품질 문제를 해결 완료로 표시하지 않는다.

## 검증

- 고도화 Jest: 24개 스위트, 290개 통과.
- R1/R2 과거 baseline의 실제 지역 ID를 고정 fixture와 대조한다. 후보 0개로 검사를 우회하지 않는다.
- R3 표본 및 경계·시설 그룹·저장 호환 검사 통과. T7 보고 도구는 구 역할과 새 역할의 요약을 분리한다.
- 하네스·포맷·린트·타입 검사 통과. 빌드는 sandbox의 Google Fonts 다운로드 제한으로 최초 실패했고, 네트워크 권한을 허용한 동일 빌드 재실행에서 통과했다.
- E2E: 12개 통과(21.0초). 최초 날짜간 편집 테스트가 첫 카드의 양일 관광을 가정하던 문제를 수정했다. 양일 관광 편집용으로 overnight 후보를 명시 선택하며 실제 날짜/시간/순서 편집·삭제·저장·복원 검사는 유지했다.
- 독립 검토에서 지적한 저장/검증/보고 경로 정리를 반영했다. 새 외부 API의 실시간 가용성을 검증한 작업은 아니다.
